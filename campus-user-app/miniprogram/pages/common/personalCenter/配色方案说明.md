# 小程序"我的"界面配色方案说明

## 一、方案概述

针对小程序端"我的"界面的用户信息卡片和钱包卡片，设计了3套符合现代UI设计标准的配色方案，每套方案都遵循WCAG 2.1 AA级对比度标准（文本与背景对比度≥4.5:1）。

## 二、配色方案详情

### 方案1：现代蓝绿系（当前已应用）

**主色调：** #4F46E5 (靛蓝) - 用户信息卡片
**辅助色：** #06B6D4 (青色) - 钱包卡片
**强调色：** #10B981 (绿色) - 交互元素

**特点：**
- 现代科技感强，适合教育类应用
- 色彩搭配和谐，视觉冲击力适中
- 蓝色系给人信任感和专业感

**具体修改点：**
1. 用户背景渐变：`linear-gradient(135deg, #4F46E5 0%, #7C3AED 100%)`
2. 钱包背景渐变：`linear-gradient(135deg, #06B6D4 0%, #3B82F6 100%)`
3. 卡片阴影与主色调协调
4. 文本对比度均符合WCAG 2.1 AA级标准

### 方案2：温暖橙棕系

**主色调：** #F97316 (橙色) - 用户信息卡片
**辅助色：** #8B5CF6 (紫色) - 钱包卡片
**强调色：** #F59E0B (琥珀色) - 交互元素

**特点：**
- 温暖活泼，亲和力强
- 橙色系给人活力和积极向上的感觉
- 适合面向家长和学生的教育应用

**具体修改点：**
1. 用户背景渐变：`linear-gradient(135deg, #F97316 0%, #EA580C 100%)`
2. 钱包背景渐变：`linear-gradient(135deg, #8B5CF6 0%, #7C3AED 100%)`
3. 卡片阴影与主色调协调
4. 文本对比度均符合WCAG 2.1 AA级标准

### 方案3：清新绿蓝系

**主色调：** #10B981 (绿色) - 用户信息卡片
**辅助色：** #3B82F6 (蓝色) - 钱包卡片
**强调色：** #EC4899 (粉色) - 交互元素

**特点：**
- 清新自然，给人舒适感
- 绿色系象征成长和教育
- 适合注重健康和可持续发展的教育品牌

**具体修改点：**
1. 用户背景渐变：`linear-gradient(135deg, #10B981 0%, #059669 100%)`
2. 钱包背景渐变：`linear-gradient(135deg, #3B82F6 0%, #2563EB 100%)`
3. 卡片阴影与主色调协调
4. 文本对比度均符合WCAG 2.1 AA级标准

## 三、文件说明

1. **当前应用方案1**：`personalCenter.wxss`
2. **方案2文件**：`personalCenter-scheme2.wxss`
3. **方案3文件**：`personalCenter-scheme3.wxss`

## 四、切换方法

如需切换配色方案，只需将对应方案的CSS内容替换到`personalCenter.wxss`文件中即可。

## 五、设计原则

1. **对比度符合标准**：所有文本与背景的对比度均≥4.5:1，符合WCAG 2.1 AA级标准
2. **色彩和谐统一**：每套方案的主色、辅助色和强调色都经过精心搭配，色彩过渡自然
3. **响应式设计**：在不同屏幕尺寸和设备上颜色显示一致，无明显色差
4. **交互反馈清晰**：为卡片、按钮等交互元素设计了明确的状态变化
5. **品牌调性一致**：所有方案都符合教育类应用的品牌定位，传达积极向上的形象

## 六、修改前后对比

### 修改前
- 用户卡片：蓝紫色渐变
- 钱包卡片：粉橙色渐变
- 文本对比度：部分不符合WCAG标准
- 交互效果：较为简单

### 修改后
- 提供3套专业配色方案
- 所有方案均符合WCAG 2.1 AA级对比度标准
- 优化了卡片阴影和交互效果
- 色彩搭配更和谐，视觉层次更清晰

## 七、应用建议

1. **方案1**：适合科技感强、面向教师和专业用户的版本
2. **方案2**：适合温暖活泼、面向家长和学生的版本
3. **方案3**：适合清新自然、注重用户体验的版本

可根据产品定位和目标用户选择合适的配色方案，或在此基础上进行进一步调整。
