# CampusTutor Web 端功能总览

## 文档定位

本文档描述当前仓库中仍在维护的 Web 端能力，替代旧版小程序功能说明。

覆盖范围：

- `campus-web-parents`（家长端）
- `campus-web-teacher`（教员端）
- `campus-web-admin`（管理端）
- `campus-web-shared`（共享层）

## 一、角色与端划分

### 1) 家长端（campus-web-parents）

- 注册登录、个人资料维护
- 学生档案管理
- 发布/编辑/上下架需求
- 教员搜索与筛选（科目、年级、距离、价格、授课方式）
- 教员详情查看、在线沟通
- 订单确认、支付、退款、进度追踪
- 课时确认与评价

### 2) 教员端（campus-web-teacher）

- 教员认证与资料完善
- 需求广场与附近需求检索
- 地图找学生与列表找学生
- 接单、开课、完课、课时打卡
- 收入流水与提现申请
- AI 工具入口（教案生成、评语润色、智能问答）

### 3) 管理端（campus-web-admin）

- 用户、教员、家长、需求、订单管理
- 审核与状态流转管理
- 钱包与流水运营管理
- 统计看板与平台配置

## 二、推荐与智能能力

### 1) 推荐引擎

- 多维规则评分：科目、年级、距离、价格、评分等
- 协同过滤（CF）混排
- 实时意图加分（近期行为反馈）
- 流量池赛马加分（BASIC/WARM/HOT）
- DeepFM ONNX 精排（不可用自动降级）

### 2) AI 能力

后端统一由 `/api/llm/*` 提供：

- 需求解析：`/api/llm/demand/parse`
- 对话助手：`/api/llm/chat`
- 快速问答：`/api/llm/quick-answer`
- 教案生成：`/api/llm/lesson/plan`
- 评语润色：`/api/llm/lesson/comment`

## 三、地图能力

后端统一由 `/api/map/*` 提供：

- 地址解析
- 逆地址解析
- 路径规划
- 距离计算

前端在需求发布、附近检索、地图找学生等场景中调用。

## 四、共享层说明（campus-web-shared）

共享层提供：

- 统一 API 请求封装
- 通用样式变量与混入
- 复用工具函数
- 可复用状态管理模块

各端通过 alias `@shared` 复用，减少重复实现。

## 五、历史说明

- `campus-web` 已在 `DEPRECATED.md` 明确标记为废弃。
- 本文档不再描述已下线或不再维护的小程序页面路径。
