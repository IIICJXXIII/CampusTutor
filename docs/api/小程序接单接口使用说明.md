# 教师接单接口使用说明

## 接口信息

| 项目 | 说明 |
|------|------|
| **接口地址** | `POST /api/order/accept` |
| **请求方式** | POST |
| **Content-Type** | application/json |
| **鉴权方式** | Header: `Authorization: Bearer {token}` |

---

## 请求参数

```json
{
  "demandId": 123,
  "totalHours": 10,
  "remark": "备注信息"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| demandId | Long | ✅ | 需求帖ID |
| totalHours | Integer | ❌ | 课时数，默认10课时 |
| remark | String | ❌ | 备注 |

---

## 响应格式

### 成功响应
```json
{
  "code": 200,
  "message": "success",
  "data": 456
}
```
- `data` 为新创建的订单ID

### 错误响应
```json
{
  "code": 400,
  "message": "需求已下架或已被接单",
  "data": null
}
```

---

## 错误码

| code | message | 说明 |
|------|---------|------|
| 400 | 需求不存在 | demandId 无效 |
| 400 | 需求已下架或已被接单 | 需求状态不是"上架中" |
| 400 | 该需求已被其他教员接单 | 已有其他教师接单 |
| 400 | 教员未认证或档案不存在 | 当前用户不是认证教师 |
| 401 | 未登录 | token无效或过期 |

---

## 业务逻辑

```
教师浏览需求 → 点击"立即接单" → 调用此接口
     ↓
接口校验需求(存在、上架中、未被接单)
     ↓
接口校验教师(已认证)
     ↓
创建订单(状态=-1待确认) + 更新需求状态为"已匹配"
     ↓
返回订单ID → 等待家长确认
     ↓
家长调用 POST /api/order/{id}/confirm → 订单状态变为0待支付
     ↓
家长支付 → 正常授课流程
```

---

## 小程序调用示例

```javascript
// utils/request.js 或 api/order.js

/**
 * 教师接单
 * @param {number} demandId - 需求帖ID
 * @param {number} totalHours - 课时数(可选)
 * @param {string} remark - 备注(可选)
 */
export function acceptDemand(demandId, totalHours, remark) {
  return request({
    url: '/api/order/accept',
    method: 'POST',
    data: {
      demandId,
      totalHours: totalHours || 10,
      remark
    }
  });
}
```

### 页面中使用

```javascript
// pages/teacher/demandDetail/demandDetail.js
const { acceptDemand } = require('../../../api/order');

Page({
  // 立即接单
  async handleAccept() {
    if (!this.data.demand) return;
    
    try {
      wx.showLoading({ title: '接单中...' });
      const orderId = await acceptDemand(this.data.demand.id);
      wx.hideLoading();
      
      wx.showToast({ title: '接单成功', icon: 'success' });
      
      // 跳转到订单详情
      wx.navigateTo({
        url: `/pages/order/detail?id=${orderId}`
      });
    } catch (err) {
      wx.hideLoading();
      wx.showToast({ 
        title: err.message || '接单失败', 
        icon: 'none' 
      });
    }
  }
});
```
