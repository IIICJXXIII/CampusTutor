| 组件 | 技术栈 | 端口 |
|------|--------|------|
| 后端 | Spring Boot 3.2.1 + Java 17 + MyBatis-Plus | 8080 |

### 1.4 安装 Docker 与 Docker Compose

```bash

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null

apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 启动 Docker 并设置开机自启
systemctl enable docker

# 验证安装

```

### 1.5 配置 Docker 镜像加速（国内必须）

```bash

# 配置阿里云镜像加速器（登录阿里云控制台 → 容器镜像服务 → 镜像工具 → 镜像加速器，获取你的专属地址）
cat > /etc/docker/daemon.json << 'EOF'

  "registry-mirrors": [
    "https://<你的加速器ID>.mirror.aliyuncs.com"
  ],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "50m",
    "max-file": "3"
  }
}
EOF

# 重载配置
systemctl daemon-reload
systemctl restart docker
```

## 三、生产环境配置文件修改

### 3.1 创建后端生产环境变量文件

```bash
# 在服务器上操作
cd /opt/campus-tutor/campus-backend

cat > .env << 'EOF'

# ---- Redis ----

REDIS_PASSWORD=<你的Redis密码>

# ---- JWT（生产环境必须修改，至少32字节随机字符串）----

JWT_EXPIRATION=86400000

# ---- 高德地图 ----

# ---- LLM (AI) 配置 ----

LLM_API_KEY=<你的DeepSeek API Key>

LLM_MODEL=deepseek-chat

# ---- 百度 OCR ----
BAIDU_OCR_ENABLED=true
BAIDU_OCR_API_KEY=<你的百度OCR API Key>
BAIDU_OCR_SECRET_KEY=<你的百度OCR Secret Key>
```

### 3.2 修改 docker-compose.yml（生产环境优化）

```bash
cd /opt/campus-tutor/campus-backend
```

将 `docker-compose.yml` 修改为生产版本：

```yaml
version: '3.8'
services:
  campus-backend:
    build: .
    container_name: campus-backend
    restart: always
    ports:
      - "127.0.0.1:8080:8080"
    env_file:
      - .env
    environment:
      - SPRING_DATASOURCE_URL=${DB_URL}
      - SPRING_DATASOURCE_USERNAME=${DB_USERNAME}
      - SPRING_DATASOURCE_PASSWORD=${DB_PASSWORD}
      - SPRING_DATA_REDIS_HOST=${REDIS_HOST}
      - SPRING_DATA_REDIS_PORT=${REDIS_PORT}
      - SPRING_DATA_REDIS_PASSWORD=${REDIS_PASSWORD}
    volumes:
      - ./uploads:/app/uploads
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_started
    networks:
      - campus-net

  mysql:
    image: mysql:8.0
    container_name: campus-mysql
    restart: always
    ports:
      - "127.0.0.1:3306:3306"
    environment:
      - MYSQL_ROOT_PASSWORD=${DB_PASSWORD}
      - MYSQL_DATABASE=campus_tutor_db
    volumes:
      - mysql-data:/var/lib/mysql
      - ./sql/schema.sql:/docker-entrypoint-initdb.d/01_schema.sql
      - ./sql/data.sql:/docker-entrypoint-initdb.d/02_data.sql
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_general_ci --default-authentication-plugin=caching_sha2_password
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost", "-u", "root", "-p${DB_PASSWORD}"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - campus-net

  redis:
    image: redis:7-alpine
    container_name: campus-redis
    restart: always
    ports:
      - "127.0.0.1:6379:6379"
    command: redis-server --requirepass ${REDIS_PASSWORD} --appendonly yes
    volumes:
      - redis-data:/data
    networks:
      - campus-net

volumes:
  mysql-data:
  redis-data:

networks:
  campus-net:
    driver: bridge
```

**关键变更说明**：
- `restart: always`：容器异常退出自动重启
- 端口绑定 `127.0.0.1`：仅本地访问，外部通过 Nginx 代理
- MySQL 健康检查：确保数据库就绪后后端才启动
- Redis 添加密码和 AOF 持久化
- Redis 数据持久化卷

## 五、Nginx 反向代理配置

### 5.1 创建 Nginx 配置

```bash
cat > /etc/nginx/sites-available/campus-tutor << 'EOF'
# 限流区域定义（防暴力请求）
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=30r/s;
limit_req_zone $binary_remote_addr zone=login_limit:10m rate=5r/m;

# HTTP → HTTPS 重定向
server {
    listen 80;
    server_name your-domain.com admin.your-domain.com;
    return 301 https://$host$request_uri;
}

# 用户端 HTTPS 配置
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate     /etc/nginx/ssl/your-domain.com.pem;
    ssl_certificate_key /etc/nginx/ssl/your-domain.com.key;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache   shared:SSL:10m;
    ssl_session_timeout 10m;

    # 用户端前端静态文件
    root /opt/campus-tutor/campus-web/dist;
    index index.html;

    # 前端路由 history 模式支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理到后端
    location /api/ {
        limit_req zone=api_limit burst=50 nodelay;
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_read_timeout 120s;
        proxy_send_timeout 60s;
    }

    # WebSocket 代理
    location /ws/ {
        proxy_pass http://127.0.0.1:8080/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 3600s;
    }

    # 上传文件静态服务
    location /uploads/ {
        alias /opt/campus-tutor/campus-backend/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # Knife4j API 文档（生产环境可选关闭）
    location /doc.html {
        proxy_pass http://127.0.0.1:8080/doc.html;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        # 可选：限制仅内网访问
        # allow 10.0.0.0/8;
        # deny all;
    }

    # 登录接口额外限流
    location /api/auth/login {
        limit_req zone=login_limit burst=3 nodelay;
        proxy_pass http://127.0.0.1:8080/api/auth/login;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2?)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 禁止访问隐藏文件
    location ~ /\. {
        deny all;
    }
}

# 管理端 HTTPS 配置
server {
    listen 443 ssl http2;
    server_name admin.your-domain.com;

    ssl_certificate     /etc/nginx/ssl/admin.your-domain.com.pem;
    ssl_certificate_key /etc/nginx/ssl/admin.your-domain.com.key;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # 管理端前端静态文件
    root /opt/campus-tutor/campus-web-admin/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        limit_req zone=api_limit burst=50 nodelay;
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /ws/ {
        proxy_pass http://127.0.0.1:8080/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }

    location /uploads/ {
        alias /opt/campus-tutor/campus-backend/uploads/;
        expires 30d;
    }

    location ~ /\. {
        deny all;
    }
}
EOF
```

### 6.2 首次启动注意事项

MySQL 首次启动时会自动执行 `schema.sql` 和 `data.sql` 初始化数据库。如果后续重启，这些脚本**不会**重复执行（Docker 的 `docker-entrypoint-initdb.d` 机制仅在数据卷为空时执行）。

### 6.3 常用运维命令


## 七、域名解析与 SSL 证书

### 7.1 域名解析配置

1. 登录阿里云控制台 → 域名 → 解析设置
2. 添加以下解析记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---------|---------|--------|-----|
| A | @ | `<你的服务器公网IP>` | 600 |
| A | admin | `<你的服务器公网IP>` | 600 |
| A | www | `<你的服务器公网IP>` | 600 |

### 7.2 SSL 证书申请（阿里云免费证书）

1. 阿里云控制台 → SSL 证书 → 免费证书 → 创建证书
2. 填写域名 `your-domain.com`，选择 DNS 验证
3. 按提示在域名解析中添加 TXT 记录完成验证
4. 下载 Nginx 格式证书，得到 `your-domain.com.pem` 和 `your-domain.com.key`
5. 对 `admin.your-domain.com` 重复上述步骤

### 7.3 安装证书

```bash
# 创建证书目录
mkdir -p /etc/nginx/ssl

# 上传证书文件（在本地执行）
scp your-domain.com.pem root@<your-ip>:/etc/nginx/ssl/
scp your-domain.com.key root@<your-ip>:/etc/nginx/ssl/

# 设置权限
chmod 600 /etc/nginx/ssl/*.key
chmod 644 /etc/nginx/ssl/*.pem

# 重载 Nginx
nginx -t && systemctl reload nginx
```

### 7.4 使用 Certbot 自动续期（替代方案）

```bash
# 安装 Certbot
apt install -y certbot python3-certbot-nginx

# 自动获取并配置证书
certbot --nginx -d your-domain.com -d admin.your-domain.com

# 自动续期（Certbot 会自动添加 cron）
certbot renew --dry-run
```

## 八、防火墙与安全组配置

### 8.1 阿里云安全组规则

在阿里云控制台 → ECS → 安全组 中添加以下规则：

| 方向 | 协议 | 端口范围 | 授权对象 | 说明 |
|------|------|---------|---------|------|
| 入 | TCP | 22 | 你的IP/32 | SSH |
| 入 | TCP | 80 | 0.0.0.0/0 | HTTP |
| 入 | TCP | 443 | 0.0.0.0/0 | HTTPS |
| 入 | ICMP | -1/-1 | 0.0.0.0/0 | Ping |

> **⚠️ 绝对不要对外暴露 3306（MySQL）和 6379（Redis）端口！** docker-compose 中已绑定 `127.0.0.1`，双重保障。

### 8.2 服务器 UFW 防火墙（额外防护层）

```bash
# 安装 UFW
apt install -y ufw

# 默认拒绝所有入站
ufw default deny incoming
ufw default allow outgoing

# 允许必要端口
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp

# 启用防火墙
ufw enable

# 查看状态
ufw status verbose
```

### 8.3 SSH 安全加固

```bash
# 修改 SSH 配置
vim /etc/ssh/sshd_config

# 建议修改项：
# Port 2222                    # 修改默认端口
# PermitRootLogin no           # 禁止 root 直接登录（需先创建普通用户）
# PasswordAuthentication no    # 禁用密码登录，仅用密钥
# MaxAuthTries 3               # 最大尝试次数

# 重启 SSH
systemctl restart sshd
```

### 10.1 Docker 构建失败

```xml
    </pluginRepository>
</pluginRepositories>
```

## 核心要点总结

1. **安全第一**：所有数据库/缓存端口绑定 `127.0.0.1`，仅通过 Nginx 代理对外暴露；生产环境必须修改 JWT 密钥和数据库密码
2. **Docker Compose 一键编排**：后端三个服务（MySQL + Redis + Spring Boot）通过 Docker Compose 管理，简化运维
3. **Nginx 双重角色**：既服务前端静态文件，又反向代理后端 API 和 WebSocket
4. **前端构建后部署**：不在线上运行 Vite dev server，而是 `npm run build` 产出静态文件由 Nginx 托管
