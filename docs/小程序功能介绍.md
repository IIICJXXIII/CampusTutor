# 📱 校园智教 (CampusTutor) 微信小程序

## 完整功能介绍文档

---

## 一、产品概述

**校园智教**是一款专为大学生家教市场打造的 O2O（Online-To-Offline）智能服务平台微信小程序。它连接**家长**（需求方）与**大学生教员**（服务方），通过数字化手段解决传统家教中介存在的三大痛点：

| 痛点 | 传统中介 | 校园智教解决方案 |
|------|---------|-----------------|
| 信息不透明 | 无法查看教员真实背景 | OCR 学历认证 + 真实评价体系 |
| 中介费高昂 | 收取首次课时费 30-50% | 仅收取 10% 平台服务费 |
| 信任建立难 | 难以验证教员资质 | 实名认证 + 课时打卡 + 担保交易 |

### 🎯 核心价值主张

> **"认证严、匹配准、服务全"** —— 构建家教服务生态闭环

---

## 二、用户角色

小程序支持**两种核心用户角色**，用户在首次登录时选择身份：

### 1. 👨‍👩‍👧 家长（需求方）
寻找家教的家长用户，可以发布家教需求、浏览教员档案、下单支付、管理课时。

### 2. 🧑‍🏫 教员（服务方）
提供家教服务的大学生用户，可以完成资质认证、接单授课、管理收入、提现结算。

## 三、功能模块详解

### 📌 公共模块 (Common)

这些功能**家长和教员**都可以使用：

| 功能 | 路径 | 说明 |
|------|------|------|
| **首页** | `/pages/common/index` | 根据用户角色自动展示不同的首页内容 |
| **登录** | `/pages/common/login` | 支持微信一键登录 + 手机验证码登录 |
| **注册** | `/pages/common/register` | 选择角色（家长/教员），完善基本信息 |
| **个人中心** | `/pages/common/personalCenter` | 查看个人资料、设置、退出登录 |
| **用户信息编辑** | `/pages/common/userInfoView` | 修改头像、昵称、手机号等 |
| **消息列表** | `/pages/common/messageList` | 系统通知、订单消息、聊天消息 |
| **聊天详情** | `/pages/common/chatDetail` | 家长与教员之间的即时通讯 |
| **错题本** | `/pages/common/wrongBook` | 拍照上传错题，AI-OCR 自动识别题目 |
| **错题详情** | `/pages/common/wrongBookDetail` | 查看错题解析、相似题推荐 |

### 👨‍👩‍👧 家长端功能

#### 1. 首页 (`/pages/parent/index`)
- 快捷入口：发布需求、我的订单、课时记录、错题本
- 我的需求列表（最近 3 条）
- 进行中的订单（最近 3 条）

#### 2. 发布需求 (`/pages/parent/publishDemand`)
四步发布流程：
1. **选择学生**：选择或添加孩子信息（姓名、年级、学校）
2. **需求信息**：填写科目、薄弱知识点、期望价格
3. **授课要求**：选择授课方式（上门/网课/均可）、时间偏好
4. **位置确认**：地图选点或自动定位，用于教员 LBS 匹配

#### 3. 我的需求 (`/pages/parent/demand/myList`)
- 查看已发布的所有需求
- 需求状态：招聘中 → 已匹配 → 已完成
- 操作：上架/下架、删除、查看匹配教员

#### 4. 匹配结果 (`/pages/parent/matchResult`)
- 基于需求智能推荐教员列表
- **智能排序算法**：综合距离、评分、价格、匹配度
- 展示匹配分数和距离信息

#### 5. 教员详情 (`/pages/parent/teacherDetail`)
展示教员完整档案：
- 基本信息：头像、昵称、学校、专业、年级
- 认证状态：身份认证 ✓、学历认证 ✓
- 授课信息：擅长科目、单价、授课方式
- 历史评价：星级评分 + 文字评价
- 操作按钮：**立即预约** / **在线沟通**

#### 6. 订单管理 (`/pages/parent/order`)
- **订单列表**：按状态筛选（待支付/待上课/进行中/已完成/已取消）
- **订单详情**：查看订单信息、教员信息、课时进度
- **支付功能**：支持微信支付 + 钱包余额支付
- **申请退款**：部分退款或全额退款

#### 7. 支付页面 (`/pages/parent/payment`)
- 订单金额确认
- 选择支付方式：微信支付 / 钱包余额
- 安全支付流程

#### 8. 电子签约 (`/pages/parent/electronicSign`)
- 在线签署家教服务协议
- 协议条款展示
- 电子签名功能

#### 9. 课时管理 (`/pages/parent/lessonList` + `lessonDetail`)
- 查看所有课程安排（日历视图）
- 课时状态：待确认 → 已确认 → 申诉中
- 确认教员打卡记录
- 对课程进行评价

### 🧑‍🏫 教员端功能

#### 1. 首页 (`/pages/teacher/index`)
- 数据统计卡片：完成订单数、综合评分、账户余额
- 快捷入口：招学生、我的订单、课时记录、我的认证、收入明细
- 附近需求列表（LBS 推荐）

#### 2. 资质认证 (`/pages/teacher/certification`)
三步认证流程：
1. **基本信息**：填写真实姓名、学校、专业、年级
2. **身份认证**：上传身份证照片，OCR 自动识别
3. **学历认证**：上传学生证/成绩单，OCR 自动识别

认证状态：待提交 → 审核中 → 已通过 / 已驳回

#### 3. 招学生 - 列表模式 (`/pages/teacher/findStudentList`)
- 展示周边家教需求列表
- 筛选条件：科目、年级、授课方式、价格区间
- 显示距离、期望价格、发布时间

#### 4. 招学生 - 地图模式 (`/pages/teacher/mapFindStudent`)
- 高德地图集成，直观展示需求分布
- 点击标记查看需求详情
- 支持缩放、拖动、重新定位

#### 5. 需求详情 (`/pages/teacher/demandDetail`)
- 查看需求完整信息
- 学生基本情况、薄弱科目
- 操作按钮：**一键接单** / **联系家长**

#### 6. 接单确认 (`/pages/teacher/orderConfirm`)
- 确认接单信息
- 填写首课时间、备注
- 提交后等待家长确认

#### 7. 订单管理 (`/pages/teacher/orderList` + `orderDetail`)
- 订单列表：按状态筛选
- 订单详情：查看学生信息、课程安排
- 操作：确认开课、标记完成

#### 8. 课时管理 (`/pages/teacher/lessonList`)
- 课程表视图（日历 + 列表）
- 每节课的时间、状态
- 快捷跳转到打卡页面

#### 9. 上课打卡 (`/pages/teacher/lessonCheckIn`)
- **签到功能**：开始上课时打卡
- **签退功能**：下课时打卡
- **拍照记录**：上传教学现场照片作为凭证
- 自动计算课时时长

#### 10. 课程表 (`/pages/teacher/teacherSchedule`)
- 周视图/月视图切换
- 显示所有已安排课程
- 冲突检测提醒

#### 11. 收入明细 (`/pages/teacher/incomeDetail`)
- **钱包概览**：可用余额、冻结金额
- **交易流水**：每笔收入/支出记录
- **提现记录**：历史提现状态

#### 12. 提现功能 (`/pages/teacher/withdraw`)
- 输入提现金额
- 选择提现方式：微信 / 支付宝 / 银行卡
- 填写收款账号
- 提交提现申请（后台审核后打款）

## 四、核心技术亮点

### 1. 🔐 双重认证体系
- **身份认证**：身份证 OCR 识别 + 人脸比对
- **学历认证**：学生证/成绩单 OCR 识别

### 2. 📍 LBS 智能定位
- 集成高德地图 SDK
- 基于经纬度计算距离
- 支持地图选点发布需求

### 3. 🤖 智能匹配算法
多维度权重计算匹配分数：
```
匹配分数 = 科目匹配(30%) + 年级匹配(20%) + 距离权重(25%) + 价格权重(15%) + 评分权重(10%)
```

### 4. 💰 担保交易机制
- 家长支付 → 金额冻结
- 教员完成课时 → 课时费解冻
- 平台抽取 10% 服务费

### 5. ⏱️ 课时打卡系统
- 签到/签退时间记录
- 拍照凭证上传
- 家长确认机制

### 6. 📱 微信生态集成
- 微信一键登录
- 微信支付
- 模板消息推送

## 五、页面流程图

### 家长端典型流程
```
登录 → 发布需求 → 查看匹配教员 → 选择教员 → 下单支付 
     → 等待上课 → 确认课时 → 评价教员 → 完成
```

### 教员端典型流程
```
登录 → 完成认证 → 浏览需求 → 接单 → 等待确认 
     → 上课打卡 → 完成课时 → 收入到账 → 提现
```

## 六、界面设计风格

### 设计理念
- **现代简约**：大量使用圆角、渐变、阴影
- **色彩鲜明**：主色调紫色 (#667eea)，辅色橙色 (#ff9900)
- **动效丰富**：按钮点击反馈、页面切换动画

### UI 组件规范
| 元素 | 规范 |
|------|------|
| 圆角 | 小组件 16rpx，卡片 24rpx，按钮 48rpx |
| 阴影 | 轻量阴影 `0 4rpx 16rpx rgba(0,0,0,0.05)` |
| 字体 | 标题 34rpx 加粗，正文 28rpx，辅助文字 24rpx |
| 间距 | 统一使用 16rpx、24rpx、32rpx 的倍数 |
