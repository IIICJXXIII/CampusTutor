### 🟣 Phase 2: LBS 地理位置与需求管理 (LBS & Demand)

*此阶段目标：让家长能“看到”老师，让老师能“看到”需求。*

* [ ] **LBS 位置服务**
* [ ] 客户端：集成 `uni.getLocation` 获取用户当前经纬度。
* [ ] 后端：实现 Redis `GEOADD` 存储教员实时位置。
* [ ] 后端：实现 `GEORADIUS` 接口，查询附近的教员/学生 。


* [ ] 客户端：实现地图找人功能 (使用 `<map>` 组件渲染 Marker) 。




* [ ] **排课与日程**
* [ ] 客户端(教员)：开发可视化学期日历，设置空闲时间段 。


* [ ] 后端：存储时间段数据 (JSON格式)，提供冲突检测逻辑 。




* [ ] **需求发布 (家长端)**
* [ ] 客户端：开发需求发布表单 (科目、年级、预算范围、上课地点) 。


* [ ] 后端：需求的 CRUD 接口实现。
