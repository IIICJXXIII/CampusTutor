# ⚠️ DEPRECATED — campus-web

本目录（`campus-web/`）已弃用，不再维护。

## 替代方案

原先由 `campus-web` 承担的功能已拆分到以下独立前端项目：

| 项目 | 说明 | 目录 |
|------|------|------|
| campus-web-parents | 家长端 Web 应用 | `../campus-web-parents/` |
| campus-web-teacher | 教师端 Web 应用 | `../campus-web-teacher/` |
| campus-web-admin | 管理后台 Web 应用 | `../campus-web-admin/` |

公共模块（API、样式、Store）统一迁移至 `../campus-web-shared/`。

## 说明

- 本目录中的代码仅作历史参考，请勿基于此目录继续开发。
- 如需查找旧逻辑，可在本目录中搜索，但所有新功能和修复应在上述新项目中实现。
